# 터미널 사용 규칙

1. 파일 읽기: `cmd /c type "path"`
2. 파일 목록: `cmd /c dir /b "path"`
3. Python 가능 여부 확인 및 스크립트 실행: `cmd /c "python ..."`
4. 긴 검색은 피하고, 필요하면 `cmd /c findstr /n /c:"패턴" "파일"`처럼 단일 파일 대상으로 검색한다.
5. 파일 수정은 `apply_patch`를 사용한다.
6. 명령 하나가 완료되면 `docs/log`의 해당 월 로그에 기록한다.
7. 로그를 쓰는 행위 자체는 중복 방지를 위해 별도로 기록하지 않는다.

# 데이터베이스 작업 규칙

## `.env` 파일

1. `.env` 파일은 직접 열람하거나 내용을 출력하지 않는다.
2. Python 프로그램은 실행 시 필요한 경우 `.env` 파일을 사용할 수 있다.

## 접근 권한

1. 데이터베이스는 사용자의 명시적 권한을 받은 경우에만 접근한다.
2. 데이터베이스 접근은 Python 프로그램을 통해서만 수행한다.
3. 데이터베이스에 직접 접속하거나 쿼리 도구로 직접 조회하지 않는다.

## 읽기 전용

1. Python 프로그램으로 교통량을 추출할 수 있으나 데이터베이스 접근은 반드시 읽기 전용으로만 수행한다.
2. Python 코드에는 데이터베이스 세션 또는 커넥션이 읽기 전용으로 동작하도록 조치한다.
3. 생성, 수정, 삭제, 마이그레이션, 초기화, `truncate`, `drop` 등 쓰기 작업은 절대로 수행하지 않는다.

## 교통량 추출 기준

1. 이 프로젝트에서 "교통량 추출"은 기본적으로 `traffic_api`로부터 교통량을 추출하는 것을 의미한다.
2. 단, 사용자의 명시적 권한을 받은 경우에는 읽기 전용 Python 프로그램을 통해 데이터베이스에서 교통량을 추출할 수 있다.
